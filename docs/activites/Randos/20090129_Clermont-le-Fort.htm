Du soleil, une douce température, pas ( trop ) de boue, et quelques points de vues assez plaisants. Ainsi peut se définir la rando de Clermont-le-Fort, que nous avons parcouru dans le sens rétrograde ( sens de rotation des aiguilles d'une montre ), alors que les autres fois, nous l'avions parcouru dans le sens direct ( l'inverse des aiguilles d'une montre, du moins de la mienne ( quelle culture !! ) ). Si notre guide savait utiliser son GPS aussi bien qu'il sait lire l'heure ce serait parfait.
JR
