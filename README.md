# AZF–Mémoire et Solidarité — le site GitHub Pages

Un **git repository** (« dépôt git ») est un dossier qui est **hébergé sur un serveur** ([GitHub](https://github.com/azf-mem-sol/site)) mais dont les administrateurs ont une **copie locale** sur laquelle ils peuvent travailler.

Ce dossier partagé contient les fichiers qui constituent le site Internet de l’association [AZF–Mémoire et Solidarité](https://www.azf-memoireetsolidarite.com/). Il permet l’**hébergement gratuit** du site sur GitHub Pages, ainsi que la **collaboration** de plusieurs personnes, qui peuvent modifier le site séparément.

## Comment utiliser ce dossier
Pour votre site Internet, j’ai simplifié le processus de modification. Chaque fois que vous voudrez modifier le fichier, vous aurez seulement **trois choses** à faire :

1. **Télécharger** la dernière version du dossier,
2. **Modifier** les fichiers localement (avec Dreamweaver ou directement en HTML), et
3. **Enregistrer** la version modifiée du dossier.

> **IMPORTANT** — Lisez bien les instructions qui suivent, car elles vous expliquent, étape par étape, le processus à suivre **chaque fois** que vous voudrez modifier le site. Vous devrez effectuer chaque étape l’une après l’autre pour pouvoir modifier votre site de façon sécurisée. Si vous avez des problèmes, appelez-moi !

1. **Télécharger la dernière version du dossier**

	* Exécutez le fichier **_télécharger.bat** (en double-cliquant).

2. **Modifier les fichiers**

	* Utilisez votre logiciel de modification (DreamWeaver ou autre) pour modifier les fichiers (ajouter une ou plusieurs pages web, changer du texte ou des images, etc.).

2. **Enregistrer la version modifiée du dossier**

	* Exécutez le fichier **_enregistrer.bat** (en double-cliquant).
	* Si vous êtes **vraiment certain·e** de vouloir enregistrer vos modifications sur le site, tapez **oui** quand le programme vous le demande, puis pressez Entrée.
	* Écrivez un **message court d’enregistrement** qui décrit les modifications (par exemple, _Ajouté une page pour la randonnée du 09 01 2025_), puis pressez Entrée.
		* **Attention** ! Il ne faut **surtout pas** entrer de caractères spéciaux (sauf apostrophes et tirets) ! Les guillemets, parenthèses, points, virgules, pourcentages, etc. sont **exclus** — vous devez vous limiter aux lettres, chiffres, apostrophes et tirets.
	* Après l’étape précédente, vos changements seront enregistrés, et seront visibles sur le site dans environ **10 minutes**.
	* Une fois ces 10 minutes passées, connectez-vous au site pour vérifier vos changements.

## Je me suis trompé, comment revenir en arrière ?

Si vous voulez **supprimer vos modifications non-enregistrées** (et revenir à l’état actuel du site), vous pouvez simplement exécuter le fichier **_télécharger.bat**.

Si vous voulez **annuler le dernier enregistrement** et revenir à la version précédente, exécutez le fichier **_marche-arrière.bat**.

> **ATTENTION** — Cette opération (_marche-arrière.bat) est **dangereuse** : elle peut supprimer définitivement des modifications que quelqu’un a apporté au site. Si vous n’êtes pas à 100% sûr·e que c’est ce que vous voulez faire, ne touchez pas à ce script, et appelez-moi !
