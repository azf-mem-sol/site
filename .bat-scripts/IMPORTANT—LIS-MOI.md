# Ne supprimez / modifiez rien dans ce dossier !

Les fichiers dans ce dossier contrôlent l’exécution des scripts qui vous permettent de communiquer avec GitHub (donc qui vous permettent de télécharger la dernière version du site et enregistrer vos modifications).

Il ne faut donc supprimer, ni modifier, aucun des fichiers ou dossiers dans ce répertoire. Pour modifier le site Internet, rendez-vous au dossier **docs**, où se trouvent tous les fichiers qui constituent le site.
